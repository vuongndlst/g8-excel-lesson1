# Kiến thức nền – Khám phá dữ liệu trong Excel

Website tĩnh dành cho GitHub Pages.

## Đưa lên GitHub Pages
1. Tạo một repository mới trên GitHub.
2. Upload `index.html` vào thư mục gốc của repository.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn nhánh **main** và thư mục **/(root)**.
6. Lưu và chờ GitHub tạo đường dẫn website.

## Nội dung
- Chặng 1: Cấu trúc dataset
- Chặng 2: Loại dữ liệu
- Chặng 3: Sắp xếp (Sort)
- Chặng 4: Lọc (Filter)
- Chặng 5: Câu hỏi nghiên cứu
- Kiểm tra cuối: 10 câu ngẫu nhiên, bao phủ đủ 5 chặng và nhiều dạng tương tác; đạt 8/10 để tải minh chứng PNG/PDF
